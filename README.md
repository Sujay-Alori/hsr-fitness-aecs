# HSR Fitness — Client Websites

Production websites built and deployed for two real fitness center clients: **AECS HSR Fitness** and **HSR Fitness World**.

🔗 Live: [aecshsrfitness.in](https://aecshsrfitness.in) · [hsrfitnessworld.in](https://hsrfitnessworld.in)

## Overview

Responsive marketing websites designed to help both gyms convert visitors into leads and members. Built with a shared, reusable component library so both sites stay visually distinct while sharing the same underlying architecture — cutting per-site development time significantly.

## Features

- **Hero, Services, Membership, Gallery, Contact, and Supplements** pages
- Click-to-connect integrations: **WhatsApp**, **Google Maps**, **Instagram**, **Email**, and call-to-action buttons for direct lead generation
- Fully responsive layout across mobile, tablet, and desktop
- Custom domains configured via Hostinger, deployed on Vercel

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI:** React
- **Deployment:** Vercel
- **Domains:** Hostinger

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/Sujay-Alori/hsr-fitness-aecs.git
cd hsr-fitness-aecs
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result. The app auto-updates as you edit files inside `app/`.

## Deployment

Both sites are deployed on [Vercel](https://vercel.com), with custom domains managed through Hostinger.
